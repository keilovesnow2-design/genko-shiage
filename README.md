# 原稿仕上げ

**原稿の言葉や文章を、登録した通りに置き換える**ツールです。
何も登録しなければ、入力した原稿はそのまま出てきます。

## 使い道の例

- **音声読み上げの読み間違い対策**
  音声ツールに原稿をそのまま入れたいけれど、特定の言葉だけ読み間違えられる。そんな言葉だけを登録して、読みを直した形に置き換えます。
- **表記ゆれの統一**
  「出来る」→「できる」、「お問合せ」→「お問い合わせ」のように、書き方の揺れを、決めた書き方にそろえます。
- **決まった言い回しの差し替え**
  よく使う一節や一文を、登録しておいた別の文章にまるごと差し替えます。

全部を変換するのではなく、**困った言葉だけを登録して、使いながら育てていく**道具です。

**使う（ブラウザだけで動きます。インストール不要）**

## できること

| 機能 | 説明 |
|---|---|
| 言葉の置き換え | 「思考」→「しこう」のように、原文と修正後を登録します |
| 一節・一文のまるごと置き換え | 長い文章を、別の文章に差し替えられます |
| ゆるく一致 | 空白や句読点が違っていても置き換えます（長い文章向け） |
| 数字の書き方 | 「日間」「個」などの単位ごとに、そのまま／算用数字（20日間）／漢数字（二十日間）を選べます |
| 読みが分かれやすい言葉の検出 | 原稿に「昨日」「一日」などが出てくると知らせ、読みを押すだけで登録できます |
| ダーク／ライト | 画面右上のボタンで切り替えできます |

置き換わった場所は、仕上がり欄で色が付きます（言葉は朱色、数字は紺色）。色の付いた所を押すと、そのルールが開きます。

## 使い方

1. 左の「原稿」欄に原稿を貼り付けます。
2. 直したい言葉があれば、ルールを登録します。
   - **「＋ ルールを追加」**を押して、「原文」と「修正後」を書く。
   - 原稿の中で言葉を選んで、**「選択した部分をルールに追加」**を押す。
   - 画面に出る「読みが分かれやすい言葉」から、読みを押して登録する。
   - 「たくさんまとめて追加する」に、`原文 → 修正後` を1行ずつ貼る。
3. 右の「仕上がり」欄を確認して、**「仕上がりをコピー」**で取り出します。

### 数字の書き方について

音声ツールによっては、同じ数でも書き方で読みが変わることがあります。

- `二十日間` →「はつかかん」と読まれることがある
- `20日間` →「にじゅうにちかん」と読まれる

このような単位ごとに、書き方を選べます。初期設定は、すべて「そのまま」（変えない）です。
日付の「二十日」や、「数十個」「何百個」のような言葉は、変えません。

## ルールの保存について

- 登録したルールは、**お使いのブラウザの中だけ**に保存されます。サーバーには送られません。
- 原稿の内容も、サーバーには送られません（すべてブラウザの中で処理します）。
- 同じURLを、同じブラウザで開く限り、ルールは残ります。
- ブラウザのデータを消した場合や、別のパソコンで使う場合は、「保存・読み込み」の**書き出し／読み込み**で引き継げます。定期的な書き出しをおすすめします。

## 作り方（開発者向け）

静的なページです。ビルドは不要です。

```
public/
  index.html      画面
  style.css       デザイン
  app.js          画面の動作
  engine.js       置き換えエンジン（ブラウザ・Node 両対応）
  watchwords.js   読みが分かれやすい言葉の一覧（ここに足すと検出が増えます）
test.js           エンジンのテスト
wrangler.jsonc    Cloudflare への公開設定
```

```bash
# テスト
node test.js

# 手元で確認（public フォルダを配信する）
cd public && python -m http.server 8765
# → http://localhost:8765

# Cloudflare へ公開（wrangler のログインが必要）
npx wrangler login
npx wrangler deploy
```

## 注意

- 「読みが分かれやすい言葉」の一覧は、候補を出すだけで、自動では何も置き換えません。実際にどう読まれるかは、お使いの音声ツールで確認してください。
